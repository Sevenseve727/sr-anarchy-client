# sr-anarchy-client – Phase 1a

Spielseite (`index.html`) und Verwaltung (`admin.html`) des KI-Spielleiters. Kein Build-Schritt.

1. Alle Dateien in das öffentliche Repo `sr-anarchy-client` hochladen.
2. In `config.js` die Adresse deines Workers eintragen (endet auf `.workers.dev`).
3. GitHub Pages ist unter Settings → Pages auf Branch `main`, Ordner `/ (root)` gestellt.
4. `…/sr-anarchy-client/admin.html` öffnen, Admin-Secret eingeben, Spieler anlegen, Codes erzeugen, Bögen einfügen.
5. Mitspieler öffnen `…/sr-anarchy-client/` und melden sich mit ihrem Code an.

Die Seite enthält nur Code. Regelwerk-Inhalte und Charakterwerte liegen ausschließlich auf dem Server.
